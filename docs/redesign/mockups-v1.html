Spicy Meal · سبايسي ميل — design proposal

Every screen, redrawn.

A first visual pass over the whole product: 22 customer screens, the twelve-state order board, and all twelve tabs of the admin dashboard. Arabic-first and right-to-left throughout, with English shown where mirroring needs proving. Built against the shipped feature inventory — nothing here removes a state that exists today.

01

The material

Brand purple and hot red are fixed. Everything else is a neutral with a purple bias so the two brand colours never sit on a dead grey. Status colour is always paired with an icon and a label — never colour alone. Dark mode redefines the tokens rather than inverting them: the red is lifted so it stays legible on a dark ground.

05

The twelve-state board

Two facts are tracked separately and never merged: whether the customer paid, and whether the order actually reached the restaurant. Exactly one state renders a success check. Two are deliberately neutral. One is ambiguous and offers no retry, because the branch may already be cooking.

These answers are now recorded in the brief and the parity inventory, and every screen above is drawn against them.

Dark mode?
In scope

Every screen, all twelve states, all twelve tabs, both languages. Tokens redefined, not inverted.

Discounts & campaigns?
Design now

Promos surface, auto-applied discount line, free-delivery treatment. The backend slice is unapplied, so the UI collapses to nothing when no campaign is live.

Address management?
Dedicated screen

List, add, edit, set default, delete — reachable from Profile and from the delivery flow. Out-of-zone flagged before checkout.

Notification UI?
Design it, don't hide it

Shipped visible while the push stack stays dormant. Still no onboarding prompt and no permission pre-ask.

"The website"?
Admin dashboard only

No public marketing page in scope. The customer web experience stays at /app.

Brand palette?
Fixed purple / red

Designed against #422e87 and #e02d3d. Tokens stay semantic because the backend override still exists, but a second palette is no longer a deliverable.
