# Scheduler deployment checklist

- [ ] `account_deletion_project_url` exists once in Vault.
- [ ] `account_deletion_process_secret` exists once in Vault.
- [ ] `verify_account_deletion_process_secret(text)` is live and service-role-only.
- [ ] `account-delete-process` is deployed from the matching merged source.
- [ ] Queue is empty before authorized no-op verification.
- [ ] Scheduler migration is applied and history-aligned.
- [ ] Cron job is unique, active, and runs every minute.
- [ ] At least two scheduled invocations return HTTP 200.
- [ ] Queue and Auth-user counts remain unchanged during no-op verification.
