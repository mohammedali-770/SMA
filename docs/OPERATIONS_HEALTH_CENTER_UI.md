# Operations Health Center — Admin UI

The Admin Dashboard receives a capability-gated **Operations Health** tab.

The page contains:

- platform overview and deterministic state;
- eight subsystem cards;
- an allowlisted scheduled-jobs table;
- a read-only Attention Required list;
- manual Refresh and automatic refresh every 60 seconds;
- Arabic RTL and English LTR presentation;
- responsive layouts and text/icon status indicators.

The UI includes no operational write action. Navigation links only open existing
Order Integrity or Integrations panels.
