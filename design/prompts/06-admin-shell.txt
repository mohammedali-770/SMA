Using the attached design system, design the Spicy Meal staff admin dashboard. Desktop artboards at 1440x900, stacked vertically with a title label above each. English left-to-right. It is operated on a shop floor during rush, so it must be built to be scanned, not read.

Every screen shares this shell: a left sidebar 220 wide on white with the SPICY MEAL wordmark and twelve navigation items — Sales Overview, Live Orders (with a red count badge showing 7), Menu Management, Banners, Branch Management, Financial Reports, Integrations, Operations Health, Operations Alerts (badge 3), Order Integrity, Settings, Legal Documents. The active item is a filled purple pill. The main area has a header row with the page title, a one-line description, and controls on the right.

Design three screens:

1. SALES OVERVIEW. Header controls: a green pulsing "LIVE 21:14:07" pill, an AR language toggle and a sound-alert button. A row of five KPI tiles — Today's sales 18,420 with a green "▲ 12% vs yesterday"; Active orders 7 with "2 awaiting POS"; Completed today 214 with "▲ 8%"; Average ticket 86.07 labelled "VAT incl." with a red "▼ 3%"; Branches closed 2 with "of 16". Below, a two-column row: on the left a card with a seven-bar daily branch sales column chart with day labels Sat to Fri, one bar highlighted in red; on the right an integration sync card listing Lazywait POS (green Realtime), Tap payments (green Live), WhatsApp OTP (green Live), Push notifications (grey Dormant) and Awaiting sync (amber, 2 orders).

2. LIVE ORDERS. Header controls: a search field reading "Search order #, client, phone…", a status filter dropdown and a sound button. Then a stack of three order cards, each with a coloured severity stripe down its left edge. Card one, red stripe: order id SM-2026-004182, chips for "Olaya · Delivery", a red "PENDING ONLINE PAYMENT" badge, timestamp 21:12, the customer name and phone, an items line reading "2× Spicy Volcano Chicken (Large, extra cheese) · 1× Crispy Fries", an explanatory line that the order is held from POS, and two buttons "Re-verify via Tap" and "Set status". Card two, green stripe: SM-2026-004181, "Nakheel · Pickup", a green "POS #5" chip, a green PAID badge, customer details and total, and a horizontal row of six status chips — Received, Preparing (active green), Ready, Out for delivery, Delivered, Cancelled. Card three, amber stripe: SM-2026-004179, "Malqa · Delivery", an amber "CASH PAYMENT REQUIRED" badge and a line noting the branch is not mapped to POS.

3. FINANCIAL REPORTS, in the ACCOUNTANT role. At the very top an amber role-warning bar reading that this is the accountant role, reports and exports are available and write actions are hidden. Header controls: a branch dropdown "All branches", a date range "2026-07-01 → 2026-07-29" and an "Export CSV" button. Four KPI tiles — Filtered revenue 412,880 noted "Includes 15% VAT"; Completed orders 4,796; Coupon savings 18,240; Delivery fees 29,410. Then a row of six report selector buttons — Sales by day (active), By branch, By product, Coupon usage, Delivery fees, POS audit. Then a data table with columns Calendar date, Orders, Gross sales, Discounts, Net, and four rows of realistic Riyadh-dated figures, numbers right-aligned.

IMAGE RULE — REQUIRED FOR THE FILE TO SAVE. Do NOT insert image assets, image fills, or any external/remote image reference anywhere in this design. Every photograph must be drawn as a rounded rectangle filled with a warm appetising linear gradient (for food: #ffd9a3 into #f4a259 into #d1512f; vary the hue slightly between dishes) and, where it helps, a small muted caption. These are photo placeholders, which is standard mockup practice — production builds swap in real product shots at the same crop. Maps are likewise drawn with vector strokes, never an image tile.
