Using the attached design system, design the core ordering loop for the Spicy Meal customer app. Phone artboards at 390x844. Arrange the artboards in a row with a title label above each.

Design these seven screens:
1. Order-type selection, PICKUP tab, in ARABIC right-to-left. A full-screen blocking gate with two tabs (استلام من الفرع / توصيل). Branch list sorted nearest-first, each row showing branch name, address, distance in km, delivery fee, minimum order, and an open/closed badge (مفتوح / مغلق). Closed branches are visible but dimmed and unselectable. Sticky continue button at the bottom.
2. Order-type selection, DELIVERY tab, in ARABIC. A map panel with a draggable red pin, a "use my location" chip, and a hint to move the pin. Below it a required location-description field with the placeholder "مثال: بقالة السلام، بجانب المسجد". Then a green in-zone confirmation showing the resolved branch and distance. Sticky confirm button.
3. Home and menu on ONE screen, in ARABIC. From the top: logo header with an EN language toggle; a branch bar showing "التوصيل من / فرع العليا" with an open badge and a change chip; a promotional banner carousel with dot indicators; a search field "ابحث عن برجر، مقبلات…"; a horizontal category chip row (الكل، برجر، دجاج، مقبلات) with the first chip active; then product cards, each with a food photo placeholder, name, description, calorie count and price, and either an "إضافة" or "تخصيص وإضافة" action. A sticky cart bar above a three-item bottom tab bar (الرئيسية، طلباتي، حسابي).
4. The SAME home screen in ENGLISH left-to-right, fully mirrored — tab order, chevrons, icon-to-text spacing and text alignment all flip.
5. Product detail in ARABIC: a large food photo placeholder at the top, name and price, description with calories, then modifier groups — a required single-select group rendered as radio rows with price deltas and a red "إجباري" badge, and an optional multi-select group rendered as checkboxes with an "اختياري · حتى 3" badge. A sticky bottom bar with a quantity stepper and an add-to-cart button showing the live total.
6. Cart in ARABIC: line rows with a food thumbnail placeholder, product name, a modifier summary line, line price, a quantity stepper and a remove action. A subtotal card noting that final fees are calculated at checkout. Empty-state variant is not needed here. Sticky checkout bar.
7. Offers and campaigns in ARABIC: a list of promotional campaign cards, each with a coloured header band, a bilingual title, the discount value as a chip (20٪ / مجاني), the minimum-order condition, and the validity window. One card is a percentage discount, one is free delivery. A footer note explaining that offers apply automatically and that promo codes go in the code field at checkout.

Rules: all sticky bars sit above the safe area. Touch targets at least 44pt. Prices are VAT-inclusive. Food imagery is drawn as gradient placeholder blocks (see the image rule below).

IMAGE RULE — REQUIRED FOR THE FILE TO SAVE. Do NOT insert image assets, image fills, or any external/remote image reference anywhere in this design. Every photograph must be drawn as a rounded rectangle filled with a warm appetising linear gradient (for food: #ffd9a3 into #f4a259 into #d1512f; vary the hue slightly between dishes) and, where it helps, a small muted caption. These are photo placeholders, which is standard mockup practice — production builds swap in real product shots at the same crop. Maps are likewise drawn with vector strokes, never an image tile.
