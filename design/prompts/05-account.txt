Using the attached design system, design the account, address and support screens for the Spicy Meal customer app. Phone artboards at 390x844, in a row with a title label above each. All in ARABIC right-to-left unless stated.

1. Login, number entry. Brand logo lockup "سبايسي ميل" and the sub-line "اطلب وجباتك الحارة المفضلة في ثوانٍ." Then a card titled "تسجيل الدخول عبر واتساب" with explanatory text, a phone field with a fixed "+966" prefix and the number entered left-to-right, the helper "أرقام الجوال السعودية فقط (+966).", and a filled button "إرسال رمز الدخول". A privacy note at the bottom.
2. Login, code entry. A card with a WhatsApp-style icon, "أرسلنا رمز الدخول إلى واتساب", the phone number, then a row of SIX separate code boxes with four filled and the fifth focused with a purple border. A filled "تحقّق وتسجيل الدخول" button, a resend countdown "إعادة الإرسال خلال 00:24", and a "تغيير الرقم" text link.
3. Profile. An identity card with a circular purple avatar showing an initial, the name "محمد العلي", a green "موثّق" verified chip and the phone number. Then a purple gradient loyalty card showing "نقاط الولاء" and a large 240. Then a grouped list: عناويني with a count, الإشعارات, اللغة showing العربية, المستندات والدعم. Then a second group: حذف الحساب in red, and تسجيل الخروج. Bottom tab bar with the profile tab active.
4. Addresses. A list of three saved-address cards. The first is the default: label "المنزل", a purple "افتراضي" chip, the description "بجانب بقالة السلام، حي الورود", a national short address code, and a green "ضمن النطاق" chip. The second is "العمل" without the default chip. The third is "بيت أمي" with a red "خارج نطاق التوصيل" chip. Each card has an overflow action. A note explaining the overflow menu offers rename, set default and delete. A sticky "+ إضافة عنوان جديد" button.
5. Notifications. A heading "الإشعارات" with the sub-line "اختر ما يمكننا إشعارك به على هذا الجهاز." Two setting cards each with a title, a description line and a toggle: "تحديثات الطلب" ON, and "العروض والترويجات" OFF. Below, an amber notice explaining that notifications are blocked in device settings.
6. Delete account, disclosure step. A heading "حذف حسابك", the line "يرجى قراءة ما سيحدث قبل المتابعة.", then a card containing a bulleted list of eight visible consequences (account access removed, saved addresses deleted, profile anonymised, loyalty points lost, sessions revoked, notification devices removed, some records legally retained, and a muted line indicating four more). Then an acknowledgement card with a checked purple checkbox and the full legal sentence. A sticky RED destructive button "متابعة حذف الحساب".
7. Legal and support. A grouped list with contact rows — "الاتصال بالدعم" with a phone icon and "الدعم عبر واتساب" with a chat icon. Note that email is deliberately absent. Then a working-hours card. Then a documents group: سياسة الخصوصية, الشروط والأحكام, سياسة الاسترجاع. A footer note that support channels appear only when an administrator enables them.
